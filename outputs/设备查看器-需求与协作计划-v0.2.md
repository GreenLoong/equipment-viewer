## 2. 业务基线

本地版本的完整目标：

1. 从 JSON 导入设备及其零件，校验后保存到数据库。
2. 列出已有设备，打开其中一台，查看零件清单和只读属性。
3. 按尺寸和位置生成基础几何体，旋转、缩放及查看全部模型。
4. 从清单选择零件，属性与三维高亮同步。
5. 隐藏选中零件、恢复全部显示。

首轮资料为只读；导入属于新增资料操作。尺寸编辑、撤销、真实 CAD 文件解析留待后续单独确认需求。

数据约定沿用最初任务：毫米为长度单位，Z 轴向上，位置表示几何体中心；box 按 X/Y/Z 给出尺寸，cylinder 给出半径和长度、轴线沿 X 方向。首份样例为 EQ-001 输送机构，包含底座、驱动电机、传动轴。

设备 ID 唯一；同一设备内零件 ID 唯一，零件名称允许重复。不同设备可以使用相同零件 ID，跨设备引用必须带设备 ID。

数据库保存设备资料。当前设备、选中零件、可见性和相机视角作为内存状态，第一版不保存这些查看状态。打开另一台设备成功后清空选择并恢复默认可见性；打开失败时保留当前设备。

## 6. F01 功能卡：首日工作

### 6.1 行为与范围

启动程序，打开固定且可写的应用数据目录中的 SQLite 文件。首次创建数据库时，在一个事务中创建必要结构并写入一台示例设备、三个零件。后续启动读取已有数据，不重复填充或覆盖。

主界面展示设备名称、零件清单与只读属性。未选择零件时，属性区域提示选择零件；点击一项后展示 ID、名称、材料、尺寸和位置。首日不依赖三维视图即可演示。

已有数据库结构异常时报告问题，保留原文件。数据库打开失败时说明失败原因，不能显示为正常空列表。首次初始化失败要回滚；事务提交失败也计为失败。

### 6.2 职责与数据流

- 数据对象 Equipment、Part：表达资料，不依赖界面控件。
- EquipmentRepository：执行 SQL，检查结果，将记录转换为数据对象，不操作控件。
- EquipmentController：打开设备、维护内存资料和 selectedPartId，协调更新。
- 界面：显示内容，将清单项携带的零件 ID 交给控制器，不直接执行 SQL。

启动读取：界面启动 → 控制器请求设备 → Repository 查询数据库 → 返回数据对象 → 控制器保存当前资料并更新界面。

选择更新：点击携带零件 ID 的清单项 → 控制器确认 ID 有效并更新选择 → 从已加载资料中找到零件 → 属性面板显示。接入三维后，沿用同一选择状态通知视图。

先用具体类完成上述职责，不预建通用插件框架。当前功能无需 API 调用层。

### 6.3 表结构与约束

| 表 | 字段 |
| --- | --- |
| equipment | id、name |
| part | equipment_id、id、name、material、shape、position_x、position_y、position_z、size_x、size_y、size_z、radius、length |

- equipment.id 为主键；part 使用 (equipment_id, id) 联合主键。
- part.equipment_id 为外键；每个 SQLite 连接显式启用并检查外键约束。
- 必填字符串不能为空白；位置为有效有限数值，可以为负。
- box 的 size_x/y/z 为正数，radius、length 为空；cylinder 的 radius、length 为正数，size_x/y/z 为空。
- 建表时落实必要的 NOT NULL、唯一、外键和检查约束；写入前同时校验数据。
- 数据值使用参数绑定，不拼接为 SQL；检查打开、执行、事务和提交的返回结果。

第一次实现时共同检查建表语句。你需要理解每个约束拒绝哪一种错误资料。

### 6.5 验收与学习检查

人工操作：

1. 首次启动看到一台设备与三个零件。
2. 依次点击零件，属性对应选中的 ID；未选择时没有残留属性。
3. 关闭并重启，数据库资料保留，记录数没有增加。
4. 使用临时测试路径制造数据库打开失败，看到明确提示，正常数据保持完整。

实现检查：使用独立临时数据库验证重复主键、无效外键及不合法尺寸被拒绝；验证中途失败的批量写入不会留下部分数据。测试不操作正常运行数据库。

你需要结合实际代码回答：两张表怎样关联；查询怎样限制设备；选中状态由谁管理；重启为什么能读到旧数据；批量写入失败时怎样避免只保存一部分。

交付内容：已实现行为和限制、启动与验收步骤、关键文件和数据流导读、实际构建与运行结果、独立审查结论及范围、未验证事项。程序能编译、能启动、功能正确、人工验收通过分别记录。

## 7. 后续导入与显隐规则

F02 导入已存在设备 ID 时拒绝覆盖并提示。缺字段、类型错误、非有限数值、未知几何类型、非法尺寸或同一设备内重复零件 ID 时拒绝整份资料。完整解析校验后再开始写事务；设备及全部零件一起提交。保存并重新读取成功后才切换当前设备。

F04 中同一时间最多选中一个零件；隐藏选中零件后保持选择和属性；选择隐藏零件只更新选择，不自动显示。显示全部后保留选择。未选中零件时隐藏按钮不可用。
