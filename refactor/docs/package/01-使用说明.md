# 设备模型查看器 · 使用说明

读者：使用本程序查看设备与零件的人。无需安装 Qt、Python 或其它环境。
版本：1.1.1（去重重构构建）。日期：2026-10-11。适用范围：本文件夹内的程序；已知限制见文末。

## 1. 启动

1. 保持整个文件夹完整（exe、`Qt6*.dll`、`platforms`、`sqldrivers` 等必须在同一层）。
2. 双击 `设备查看器.exe`。程序默认打开**设备查看器**并载入内置样例设备“输送机构 (EQ-001)”。首次启动较慢属正常（要加载 Qt 与几何）。
3. 也可以在命令行指定参数：

| 参数 | 作用 | 说明 |
| --- | --- | --- |
| 无参数 | 打开设备查看器（默认） | 与本文件夹的用途一致 |
| `--equipment-view` | 打开设备查看器 | 显式写出默认行为 |
| `--database <路径>` | 指定资料库文件 | 不指定时为 `data\records.sqlite`（程序所在目录） |
| `--record-view` | 打开旧版“记录示例”窗口 | 保留的历史功能，与设备查看无关 |
| `--equipment-check` | 只打印设备与零件清单后退出 | 命令行排查用，不打开窗口 |
| `--smoke-test <png>` | 用临时资料库截图后自动退出 | 自动检查用 |
| `--help`、`--version` | 查看参数与版本 | — |

4. `启动设备查看器.cmd` 与双击 exe 等效，区别是出错时会停在窗口里显示原因，便于排查。

## 2. 界面与操作

窗口分三栏：左侧零件清单与搜索，中间三维装配工作台与查看控件，右侧只读属性。

### 2.1 选择与查找

- 单击左侧清单中的零件即可选中，右侧显示该零件的只读参数，三维视图同步高亮。
- 搜索框按“名称或零件 ID”过滤清单；过滤只影响清单显示，不改变模型的显示与隐藏状态。若当前选中的零件被过滤掉，选择会被清空。
- 单击“清除选择”或按 `Esc` 只清除选择，不退出单件展示。
- 在三维视图中短点零件可直接选中；双击空白处只清选择，单件展示保持不变。

### 2.2 三维视图

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 旋转（彩色装配、工程轴测模式下） |
| 右键拖动 | 平移视角；不改变选择 |
| 滚轮、中键拖动 | 缩放 |
| 短点零件 | 选中该零件 |
| 双击空白 | 清除选择，保留单件展示 |

视图与显示开关（位于三维视图上方）：

| 控件 | 选项与效果 |
| --- | --- |
| 视图模式 | `01 彩色装配`（彩色+透视）、`02 工程轴测`（灰白工程色）、`03 二维投影`（前视 XZ／俯视 XY／侧视 YZ 正交）、`04 三视图`（正/俯/右三栏，同一毫米比例） |
| XYZ 位置 | `右下角`、`模型旁`、`同时显示`、`隐藏`；坐标轴按世界 XYZ 的真实投影随视角实时转动，某根轴接近视线方向时会压成一个圆点（说明该轴正指向你自己），不会出现三根轴一样长或方向突然翻转 |
| 包络尺寸 | 默认关闭；开启后在画布边缘以毫米列出选中件（或唯一可见件、整体显示包络）的 XYZ 尺寸 |
| 毫米网格 | 默认开启；贴模型底部的受限地面网格，步长按模型尺度自动取 1/2/5 毫米档并在右下角标注 |
| 装配轴 | `自动装配轴`（取中心跨度最大轴）或指定 `展开 X/Y/Z` |
| 整体展开 | 沿包络中心把各零件按当前轴有序向外分开，0–100%；“整体复原”清除全部显示偏移 |
| 选中件单独拉远 | 只把选中件沿当前轴额外拉远，0–100%；“复原单件偏移”只清该件偏移 |
| 重合件备用方向 | 多件同轴中心重合时选择正/反向，避免拉远方向不确定 |
| 选中件颜色 / 恢复自动配色 | 自定义选中件的显示颜色，或恢复稳定自动配色 |
| 隐藏选中 / 单件展示 / 显示全部 | 隐藏当前零件；只显示当前零件；恢复全部零件并退出单件展示 |
| 视角回正 / 适配全部 / 聚焦选中 | 恢复默认视角；把全部可见件纳入视野；聚焦当前选中件 |

所有查看操作只改变**显示**：零件原始中心位置与尺寸不会被改写，属性栏里“原始中心位置”与“当前显示位置”分开列出，展开与拉远导致的偏移会写在“当前显示位置”中并标注不保存到资料。

### 2.3 只读属性

零件 ID、名称、材料、形状，CAD 零件的来源文件名与 SHA256（截断显示，鼠标悬停可看完整值），原始中心位置 XYZ（毫米），当前显示位置 XYZ（毫米），显示偏移 XYZ，以及长方体尺寸或圆柱半径/长度。参数一律只读。

单位约定：毫米；Z 轴向上；圆柱轴线沿 X 方向；位置为几何体中心。

## 3. 导入自己的数据

点“导入 JSON / STEP”，按扩展名分流：

### 3.1 JSON 设备资料

- 文件上限 5 MiB，零件数上限 10000。
- 顶层字段：`equipmentId`、`equipmentName`、`parts`。
- 每个零件：`id`、`name`、`material`、`shape`、`dimensions`、`position`。
- `shape` 只接受 `box`（`dimensions` 三项：长宽高）与 `cylinder`（`dimensions` 两项：半径、长度）；`position` 恒为三项。
- 数值必须有限，尺寸必须大于零；文本不能为空白；同一设备内零件 `id` 不能重复。
- 已存在的设备 ID 会被拒绝覆盖，原设备与资料保持不变。

最小示例（保存为 `example.json` 后导入）：

```json
{
  "equipmentId": "DEMO-001",
  "equipmentName": "示例设备",
  "parts": [
    { "id": "P-001", "name": "底座", "material": "Q235", "shape": "box",
      "dimensions": [600, 300, 40], "position": [0, 0, 20] },
    { "id": "P-002", "name": "传动轴", "material": "45钢", "shape": "cylinder",
      "dimensions": [20, 400], "position": [120, 0, 120] },
    { "id": "P-003", "name": "驱动电机", "material": "铝合金", "shape": "box",
      "dimensions": [200, 160, 160], "position": [-150, 0, 120] }
  ]
}
```

### 3.2 STEP / STP 装配

- 只接受 `.step` / `.stp`，文件上限 100 MiB，转换最长等待 120 秒；转换期间可继续旋转和查看当前设备，也可点“取消CAD导入”。
- 只接受**闭合实体**；独立开放面、壳、线或混合文件会被整份拒绝，不会交付半个模型。
- 转换在本机由 `cad-runtime` 里的私有 Python/OCP 完成，不需要系统 Python，也不上传模型。
- 导入成功后按真实曲面网格显示，尺寸为全局外包络（非制造标注）；失败或取消时原设备与资料保留。

## 4. 数据存在哪里

- 默认资料库：`data\records.sqlite`（程序所在目录）；用 `--database` 可指定到其它位置。
- 删除该文件（或整个 `data` 目录）后重新启动，程序会重新建立内置样例设备 EQ-001（底座、驱动电机、传动轴三个零件）。
- 程序不会写入注册表，卸载只需删除整个文件夹。

## 5. 团队共享库（可选，本文件夹不含服务端）

“团队共享库”按钮用于访问团队 HTTP 服务（设备发布/下载与工艺批注）。该服务需要另外部署的本地 MySQL 与 Node 服务，**本交付文件夹不包含服务端**；未部署时点击会提示连接失败，属预期行为，不影响本地查看功能。服务地址与访问令牌在窗口内填写，不写入本说明。

## 6. 常见问题

| 现象 | 检查依据 | 处理办法 |
| --- | --- | --- |
| 双击后没有任何窗口 | 任务管理器是否出现进程；是否只复制了单个 exe | 确认 `Qt6*.dll`、`platforms\qwindows.dll`、`sqldrivers\qsqlite.dll` 与 exe 在同一层；重新完整解压 |
| 提示缺少 Qt 平台插件（no Qt platform plugin could be initialized） | `platforms` 目录是否缺失或被杀软隔离 | 恢复该目录；把文件夹加入杀软白名单 |
| 提示“CAD运行库不完整，请检查cad-runtime” | `cad-runtime\python.exe`、`convert_step.py` 是否存在 | 恢复 `cad-runtime` 目录；不需要 STEP 导入时可忽略该提示 |
| 提示“数据库未打开或未完成初始化” | 程序所在目录是否可写（如放在 `C:\Program Files` 下） | 把整个文件夹移到有写权限的位置，或用 `--database <可写路径>` 启动 |
| 导入 STEP 报“退出码非 0”或超时 | 文件是否为闭合实体、是否超过 100 MiB | 先在 CAD 软件里检查实体是否闭合；拆小文件；重试或取消后换文件 |
| 导入 JSON 报字段错误 | 报错会指出 `parts[i].字段` | 对照第 3.1 节的字段与取值规则修正 |
| 资源管理器里图标显示为默认图标 | 是否用的是旧版本 exe；图标缓存 | 确认使用的是本文件夹的 `设备查看器.exe`；必要时删除桌面快捷方式重建，或重启资源管理器 |
| 首次启动明显变慢 | 首次加载 Qt 与几何 | 属预期；后续启动更快 |

## 7. 已知限制

- 尺寸读数是**全局外包络**，不是制造级标注；不支持公差、基准与工程图导出。
- 不支持 CAD 编辑、布尔运算、IGES 与厂商原生格式（如 `.sldprt`、`.catpart`）。
- 团队共享库、工艺批注需要另行部署服务；本文件夹为单机运行版。
- 显示名只是协作演示用标识，不是独立账号或权限体系。
- 已在当前这台 Windows 电脑上用 Qt 6.11.1 运行验证；其它机器、高 DPI 多显示器组合、超大型装配（十万级三角以上）与长时间连续运行尚未验证。
- 参数只能查看，不能编辑回写；展开与拉远只是显示效果，不代表真实装配顺序、运动或碰撞约束。
