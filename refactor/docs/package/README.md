用途：说明这个文件夹里的程序是什么、怎么开始用、出问题查哪里。
读者：拿到本文件夹的使用者（无需开发环境）；工程与设计细节见技术说明。
版本：1.2.0（去重重构正式版，已移除团队共享库）。生成日期：2026-10-11。当前状态：可双击直接运行，已通过自动检查与原生图形验收；尚未在其它电脑与长期运行场景验证。

## 先做这一步

双击文件夹里的 **设备查看器.exe**。程序会打开设备模型查看器并自动载入内置样例设备“输送机构 (EQ-001)”。首次启动会在同目录创建 `data\records.sqlite` 保存你的设备资料；删除该文件即可恢复出厂样例。

想用命令行或排查启动参数，先看 [01-使用说明.md](01-使用说明.md)。

## 文件夹结构

| 路径 | 作用 | 能否删除 |
| --- | --- | --- |
| `设备查看器.exe` | 主程序，已嵌入应用图标 | 否 |
| `Qt6*.dll`、`libstdc++-6.dll` 等 | 运行库，必须与 exe 同目录 | 否 |
| `platforms\`、`sqldrivers\` 等 | Qt 插件（窗口平台、SQLite 驱动、图片格式等） | 否 |
| `cad-runtime\` | STEP/STP 导入用的私有 Python + OCP 运行库（约 176 MB） | 可删，删除后仅失去 STEP 导入能力 |
| `samples\` | 虚构 JSON 样例与公开 STEP 样例（含来源许可） | 可删 |
| `data\` | 首次运行后生成，保存本机设备资料 | 可删，删除即恢复出厂样例 |
| `文档\` | 本说明与其它文档 | 可删 |
| `设备查看器.ico` | 图标文件，可直接用于创建快捷方式 | 可删 |
| `启动设备查看器.cmd` | 与双击 exe 等效的命令行入口，出错时保留窗口显示原因 | 可删 |
| `manifest.json` | 交付清单：版本、源码提交、文件数与可执行文件哈希 | 建议保留 |
