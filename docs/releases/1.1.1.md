# 1.1.1 交互与显示修复

2026-10-10。来源是用户对 1.1.0 桌面版的实机反馈，四条现象都在原生Qt/OpenGL路径复现并修复，未改变数据模型与数据库结构。

## 修复内容

1. 右键不能拖动视角。网页预览版用 OrbitControls 默认按键（左键旋转、中键缩放、右键平移），桌面版此前只处理左键。现在：左键拖动旋转，右键拖动平移（二维正交前/俯/侧视同样可用，正交视图不旋转），滚轮或中键拖动缩放；右键与中键拖动都不改变选择，也不弹右键菜单；“视角回正/适配全部”把平移与缩放一起复位。
2. 右下角世界坐标轴与网页版不一致。改成网页版画法：固定像素长度、末端实心圆点、加粗字母、按深度排序（近轴后画），并带“世界 XYZ”标题；角落与“模型旁”两种位置共用同一画法，颜色统一为 X 红 / Y 绿 / Z 蓝。
3. 锯齿明显。此前只对控件格式请求4倍多重采样，实际生效无法独立确认；现在三维绘制进入自建的多重采样帧缓冲（请求4倍），再加1.5倍超采样（高DPI屏幕不叠加），先同尺寸解析多重采样、再线性缩放写回控件帧缓冲；驱动不支持帧缓冲blit或多重采样时如实回退并在状态串中报告真实采样数，不把请求值当成实测值。
4. 放大后背景出现放射状平行线。旧网格是归一化平面上向外延伸约2个单位的无限平面，深缩放时线束向消失点收敛；改为受限地面网格：格距按源毫米尺度取 1/2/5×10ⁿ 自适应档位，方阵范围随可见几何收敛（每族≤29条、总计≤58条），贴着可见几何下方绘制并用真实深度遮挡，地面与视线接近平行（正视/右视）时不绘制以免重合线叠加变亮。

另外修掉了随之暴露的一处画笔状态泄漏：坐标轴设置画刷后未恢复，三视图的栏边框 `drawRect` 会用该画刷填充整栏，导致三视图整片被实体色覆盖。现在坐标轴绘制在 save/restore 内完成。
