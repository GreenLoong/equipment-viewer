# 0.6.0 不可变设备缓存与故障回源

日期：2026-10-08。官方Redis7.4.7在用户恢复的WSL Ubuntu-24.04运行，Windows前台桥连接项目专属6380；没有重启全局WSL。Node核心客户端固定@redis/client6.3.0。只缓存合法鉴权后的设备详情，列表、批注和发布均继续MySQL。

HIT返回校验后的同ID几何；MISS回源并best-effort SET EX；不可用/容量/超时为BYPASS。固定Lua先原子检查TYPE/STRLEN再GET，巨型值不返回Node parser；坏JSON、UTF8、几何、错ID和非string定向删除。TTL默认60秒，不负缓存404。SQL实际get尝试计数独立记录，status不输出密码/key/namespace/路径。

独审修复R06-01未确认桥child漏出连接预算、R06-02同binary别目录PID归属、R06-03取消后晚凭证仍建连接；都补有界收尾与回归。备份CLI管道失败会终止并等待真正close，kill抛错也继续收尾，未确认独立报错；不能把kill请求当退出。
