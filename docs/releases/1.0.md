## 使用与维护

将Windows ZIP解压到可写目录，保留DLL/插件/cad-runtime，双击“启动设备查看器.cmd”。首次创建虚构输送机构；通过“导入 JSON / STEP”选samples中的设备或公开轴承/电机，点击清单/模型查位置、尺寸和来源。通用包不含你的资料或凭证，SQLite在该包data/viewer.sqlite。

本地查看独立运行。团队功能需要项目独立MySQL3310、Node HTTP8765及可选Redis6380；服务与薄客户端配置见api/README.md，不将数据库账号发客户端。已下载依赖与服务保留，原MySQL80和WSL全局不操作。源码构建入口README、scripts/build.ps1；资源入口api目录npm run test:resources；恢复测试只能使用指定临时/ev_test，不对正常库执行。

Git保存源码，不恢复数据库。旧程序可能不认识网格升级结构，回看旧版时使用独立目录和升级前快照，当前资料保留；禁止以删库、reset --hard/clean丢弃工作。额度恢复先看AGENTS/working-state/handoffs和实际Git/服务状态，不默认旧Agent或进程还活着。

## 验证边界

已完成自动技术检查、Agent模拟试用和独立源码/包审查；真实用户仅明确验收过环境/记录与F01-1，新版本需用户实际体验，不伪造真人验收。Qt16CTest完整集成23.75秒、转换器14项、Node38项、真实MySQL/Redis、原生图形与包运行结果均按各版来源记录，不冒充所有检查都在1.0重复运行。

Node有限GC堆观察约增加0.5MiB且逐批递增，未证明原因或长期平稳；Qt/driver资源波动原因未单独定位。指定窗口/SQL/reply/socket/任务与活动libuv在有限负载回基线，不等于零泄漏，MinGW没有ASan验证。跨电脑、Linux桌面、最大复杂装配与长期生产压力未验证。

CAD只支持完整闭实体STEP；开放面/壳/线及混合文件整份拒绝，IGES/厂商原生格式/CAD编辑/制造标注未实现。CAD当前本地保存，团队发布明确拒绝；材料缺失显示未提供。工艺作者名是显示标签，共用Bearer不是独立账户体系。通用包未公开部署或附服务器/密码。

曾有一次CAD回调测试等待失败未再复现，诊断-only改动及失败日志保留，未虚称找出原因。已识别的拓扑丢失、预算/包络/SHA、Job退出、缓存信任问题均按独审修复复验。三条非阻断Agent建议（属性格式、友好错误、聚焦薄件）作为1.1候选见simulated-feedback，不无限扩展挡当前交付。
