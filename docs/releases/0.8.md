# 0.8.0 STEP机械模型导入

日期：2026-10-09。状态：集成验证与运行库包装中，尚未发布。GitHub稳定版本仍为0.7.0。

用户从主窗口选STEP/STP，独立CAD内核读取闭合实体、装配变换和毫米单位，真实网格经校验后以事务保存SQLite；重启可重新显示、拾取、显隐、隔离、搜索和读取外包络。窗口异步等待，可取消，失败保持原设备。

公开608ZZ轴承为1实体、1444顶点/1428三角形，外包络22×22×7mm，真实通孔可拾取验证。公开Yellow减速电机为6实体、4162顶点/4332三角形，六个全局中心不同。样例来源固定FreeCAD-library提交f5ca01c，CC-BY3.0作者、源文件与摘要在samples/cad/README.md。

旧候选NEMA含四个独立开放壳，早期转换只提取六闭实体丢了其余几何。独审R08-W01后改为完整拓扑检查、整份拒绝不支持几何，旧NEMA仅留忽略目录作失败保护测试，不列作支持样例。当前不支持开放面/壳/线、IGES、CAD编辑或CAD团队共享；上传按钮在本地明确拒绝，不上传包围盒冒充CAD。

## 实现与审查范围

- 数据层：有限网格与整数索引、引用包络双边校验、精确64位SHA；EVM1二进制无压缩；先核BLOB头和累计预算再读取。已知旧SQLite结构事务迁移并核行数/外键/完整性，未知库保留拒绝。
- Scene：真实三角形位置与曲面/通孔、拾取和毫米标尺，原生OpenGL与明确软件回退分别验证。
- 转换器：私有Python3.14.8与OCP7.9.3.1，100MiB输入、1000实体、600000顶点、400000三角、64MiB结果。
- 进程：Qt异步QProcess；Windows自有Job从出生附加2GiB/KillOnClose，120秒期限。结果/释放目录/新操作前核ActiveProcesses为0，未知退出保留忙状态和临时资料。
