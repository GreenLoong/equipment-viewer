0.3至0.9已经逐版发布；1.0源码、最终包和模拟试用独审通过，远端结果见docs/working-state.md。每版保留独立Git检查点与包，原远端文档历史通过1b6ba2b合并保留，不force push。

后端环境只读发现：Node24.18已装；Windows MySQL8.0.42已装并有原MySQL80服务，必须创建项目独立实例3310，不用原数据/账号。WSL Ubuntu24.04可运行但网络modeNone；Redis官方源码可由Windows下载再在WSL编译，使用项目桥接，不改全局WSL配置。具体运行脚本实施前检查。

恢复先读AGENTS、规范、本文、handoffs，再核对git状态/当前版本/实际服务进程。令牌、数据库、node_modules和下载runtime忽略。已有SQLite快照与0.2检查点继续保留。真实用户未验收新版；模拟反馈明确标注来源。

## 公司任务派发与角色

当前采用主管加三位Agent协作；同一文件只有一位负责人，构建和ev_test使用串行调度。主管负责派发、集成、文档、版本门槛与Git；后端工程师实现HTTP/MySQL/Redis；独立审查工程师读取实际差异并编写资源/故障验证；模拟用户扮演工艺工程师操作界面、提出有限业务反馈及使用验收。实现者的自查不能代替独立审查。
