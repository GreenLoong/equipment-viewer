# 设备模型查看器 0.8 使用说明

适用于当前 Windows 电脑。此项目为工业软件工作模拟，示例资料为虚构数据。

## 打开程序

将交付 ZIP 解压到可写目录，双击“启动设备查看器.cmd”。首次启动自动创建示例“输送机构”；不需要安装数据库服务。请保留程序旁的 DLL 和插件目录。

## 查看设备与模型

1. 从顶部“当前设备”切换已有设备。
2. 点击左侧零件，右侧显示只读名称、材料、形状、位置和尺寸，模型高亮。
3. 在模型区域拖动鼠标左键旋转，滚轮缩放；短点击模型可选择零件，点击空白或按 Escape 清除选择。
4. “视角回正”恢复默认观察方向和缩放；“隐藏选中”临时隐藏零件；“显示全部”恢复零件。
5. “隔离查看”只显示选中零件；该模式下双击清单另一件会切换为仅显示该件。单击仍只更新选择和属性；点击“显示全部”退出隔离。
6. 左侧搜索名称或 ID，只过滤清单，不改变模型可见性。选中行被过滤时，属性与高亮清空；点击模型中被过滤的零件会自动清空搜索并同步选中。

## 导入设备

点击“导入 JSON / STEP”，选取 samples 中的 JSON 或 samples/cad 中的 STEP 样例。新设备保存后自动打开，重启可从设备列表选择。相同设备 ID 重复导入会拒绝覆盖。文件错误会在窗口底部指出原因，原设备仍可查看。

JSON 每个文件最多 5 MiB、10000 个零件。形状支持 box 和 cylinder；尺寸与位置为毫米，Z 向上，位置表示中心，圆柱沿 X 轴。资料参数当前只读。

STEP/STP使用随包CAD内核读取闭合实体及装配位置，显示真实三角网格。样例包括有通孔的608ZZ轴承和六实体Yellow减速电机，来源与CC-BY署名见samples/cad/README.md。开放面、壳、独立线及混合文件整份拒绝，避免只导入一部分；不支持IGES、原生厂商CAD格式或CAD编辑。

CAD位置为全局外包络中心，X/Y/Z为毫米外包络尺寸，不能当作制造图纸或质量中心。有源名称则保留，材料缺失显示“未提供”。文件SHA256作为设备身份，相同内容不能重复覆盖。最多100MiB输入、1000实体、600000顶点、400000三角形、64MiB结果、120秒转换；转换进程受2GiB约束。等待时可操作原模型或点击取消；失败保留当前设备。

CAD网格本地SQLite保存，重启可查看。当前团队服务仅共享JSON基础几何，CAD发布会明确拒绝；不会上传包围盒代替CAD。运行目录的cad-runtime须完整保留，不需安装系统Python。

## 保存与恢复

设备资料保存在程序目录的 data/viewer.sqlite；临时选择、隐藏、搜索和相机不跨重启保存。普通复制备份或迁移前，请先关闭所有使用该数据库的程序，再复制整个运行目录或数据库文件。运行中需要备份时，使用工程的一致性备份工具。源码 Git 回退不能恢复运行数据库。

0.8增加网格结构，旧版程序可能不认识升级后的数据库。回看旧版时使用独立目录和升级前快照，保留当前库；不要用删库或覆盖当前资料解决版本不兼容。

## 已知限制

原生三维使用 OpenGL；驱动不支持时使用软件三维投影回退。软件遮挡排序对相交几何的精度低于原生深度缓冲。复杂设备性能尚未测量，极端坐标跨度的小零件可能低于显示精度。本轮本机验证不代表已在其他 Windows 电脑验证。

技术检查和Agent模拟验收分别记录；新版真实用户验收待实际操作。搜索和隔离的初版来自模拟反馈，0.7交互与0.8 CAD来自用户实际反馈。

## 0.4团队共享库

主窗口点击“团队共享库”，连接已启动的团队服务。当前工程启动会读取忽略的api/runtime/client.local.json自动填入地址和遮蔽的访问令牌；通用桌面包不包含你的令牌，需提供仅host/port/token的客户端配置（EQUIPMENT_SERVICE_CONFIG）或在窗口填写。

“发布当前设备”将本地当前模型保存到共享库；另一客户端“刷新共享库”后选择设备并“下载到本地”，可离线继续查看。重复ID拒绝覆盖。服务失败、超时或响应不完整时本地资料保留。关闭窗口取消等待，但服务器可能已经完整提交；刷新确认，不盲目重发操作。

后端代码在api，安装npm ci --ignore-scripts；项目独立MySQL初始化/恢复执行node api/tools/setup-mysql.mjs setup（只本机专属3310，原MySQL80保留）。API启动执行node api/src/server.mjs，默认仅127.0.0.1:8765。配置和密码不上传，MySQL资料由独立备份恢复，不由Git恢复。

## 0.5工艺批注

共享库中选择设备及“关联零件”。选择具体零件只查询该零件；整台设备范围展示设备全部批注，新建意见关联整台设备。作者显示名仅供阅读，不是独立账号认证。输入显示名和草稿，点击“新增批注”保存；修改已有意见时按钮显示“提交修订（版本 N）”。设备几何仍只读。

批注列表选中意见后，“已保存内容”与“草稿”分别展示。两人编辑同一修订时，后提交者收到冲突提示，草稿保留；先刷新查看已保存的新内容，再自行决定是否明确提交草稿。刷新不会自动提交或覆盖草稿。时间显示为UTC，修订号每次成功修改增加。

新增结果不确定时，保持原草稿并再次明确提交会使用同一请求ID，避免重复新增。如果其他人已修改该意见，重试取得当前保存版本并保留不同草稿，需要再明确提交修改。改变新增内容会形成新请求；不确定时宜先刷新核对，避免把不同内容当作原请求重试。

有未保存草稿时，Escape、关闭按钮和标题关闭会取消等待并保留窗口；先保存或点击“放弃草稿”后才可关闭。等待取消不能撤销服务器已提交的修改。草稿保存在当前窗口内存中，进程被强制终止时不保证保留。批注列表仅返回最近200条。

## 0.6缓存与本机服务

设备重复读取可使用Redis缓存；缓存不可用会回源MySQL，批注始终读取MySQL。用户沿用共享库操作，不需要填写Redis密码。性能取决于模型和环境，本机两个零件样例的测试不代表大型装配性能。

服务维护者在api目录执行 `node tools/setup-redis.mjs setup` 恢复已标记的WSL项目实例，然后用单独终端前台运行 `node tools/redis-bridge.mjs`；另一终端运行 `node src/server.mjs`。独立MySQL3310仍须就绪。正常配置可选redis.enabled开启缓存，详情接口X-Cache与鉴权后的/api/status用于诊断；完整配置见docs/api-contract.md。此工具只针对项目Redis，不更改WSL全局网络配置。

本机已启用缓存，服务默认仍只监听127.0.0.1。通用桌面包不附带服务器、WSL、数据库或密码，本地查看功能可独立使用。真实CAD导入与新三维交互按后续0.7/0.8分别交付，不属于0.6支持范围。

## 0.7三维与毫米标尺

水平拖动旋转已按真实反馈反转，垂直拖动保持原规则。原生绘制请求4倍抗锯齿，本机实际FBO为4 samples；不支持时按实际能力报告并可软件回退。

画布的毫米比例尺以模型中心截面为参考，缩放或窗口尺寸改变时更新。选中且可见零件显示全局X/Y/Z外包络尺寸标线；圆柱注明轴向长度和外径。透视下不同深度的屏幕比例不同，短投影标线会省略以保持可读，数值仍显示。外包络不是制造图纸标注，CAD模型沿用该表达。
