## R08：真实机械CAD查看（0.8，先技术验证）

用户希望直接导入机械零件CAD文件，而非只有JSON基本几何。首选STEP/STP只读导入，以实际CAD内核读取实体/装配位置并离散化显示真实曲面；不把包围盒或新生成的简单立方体称作CAD模型。模型样例从公开来源下载，保存来源、固定版本/哈希、许可证和作者归属；不能伪造模型参数。

优先验证独立转换进程与Qt渲染的边界，避免不匹配的MSVC CAD库直接链接MinGW Qt。导入失败、过大/坏文件和转换超时保留当前设备及正常库；输出网格/参数必须校验有限数值、索引和资源上限，保存成功才替换查看状态。尺寸使用源文件单位换算毫米，CAD外包络尺寸与制造标注区分。原JSON仍可用。

装配分件、网格持久化、共享API是否支持CAD以及最终包的CAD运行库，技术验证后在本文件追加冻结设计再实现；不能把未确定方案写为完成。目标是用户选择STEP便能查看真实机械样例、选中/显隐/隔离与尺寸表达，不需要用户手工运行转换命令。
