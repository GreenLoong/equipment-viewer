# 设备模型与零件信息管理工具

用于学习 C++、Qt、数据库和三维交互的工业软件模拟项目。

远程仓库：[GreenLoong/equipment-viewer](https://github.com/GreenLoong/equipment-viewer)，私有仓库。

## 当前状态

项目处于准备阶段，已有需求与协作计划，尚无可运行应用。

首个功能 F01：使用 SQLite 保存示例设备和零件，重启后读取，在 Qt 清单中选择零件并查看只读属性。

建议技术：C++17、Qt Widgets、Qt SQL、SQLite。Qt 版本、编译器和构建方式待实际验证。

## 需求与开发流程

[需求与协作计划 v0.2](outputs/设备查看器-需求与协作计划-v0.2.md) 是当前需求、功能拆分与验收的依据。

每个小功能按“实现、运行验证、独立审查、修复、代码导读、人工验收”推进。人工验收通过后进入下一功能。

开发者编写或修改关键业务逻辑；AI 提供骨架、解释、调试和审查。

## 构建与运行

尚未建立应用工程，目前没有可执行的构建、运行或测试命令。F01 环境验证后在此记录实际命令、版本和结果。

## 数据与版本管理

- 运行数据库、本地配置、凭证和生成物不进入版本管理。
- 虚构样例和初始化代码随功能实现加入版本管理。
- 数据库修改需要单独考虑备份与恢复；源码提交不能恢复运行数据库。
- 当前没有发布或部署配置。
