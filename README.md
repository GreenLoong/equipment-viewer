# 工业设备 / CAD 查看器（设备模型查看器）

Windows 桌面端设备与机械 CAD 查看器：导入 JSON 设备参数或真实 STEP 装配模型，本地持久化，三维查看。
技术栈为 C++17 + Qt 6 Widgets + OpenGL + SQLite；STEP 转换由随包分发的私有 Python/OCP 运行库
在独立进程内完成，使用者不需要安装 Python 或 CAD 软件。

**当前正式版本：1.2.0** — 正式源码树在 [`refactor/`](refactor/README.md)，可执行文件为 `设备查看器.exe`。
本版按用户要求**整体移除“团队共享库 / 工艺批注”**这一可选服务（客户端、Node/MySQL/Redis 服务端、
相关测试与契约文档一并删除，主程序不再链接 Qt Network）；1.1.1 及更早的历史实现完整保存在 Git 标签 `v1.1.1`。

## 能做什么

- **导入与持久化**：导入 JSON 设备（`box`/`cylinder` 参数）或 `.step`/`.stp` 闭合实体与装配，
  保存到本地 SQLite（`data/records.sqlite`），重启后逐字段还原；重复设备 ID 或重复 CAD 内容拒绝覆盖。
- **三维查看**：旋转、平移、缩放、短点拾取、高亮、隐藏、隔离、显示全部、按名称或零件 ID 搜索。
- **装配视图**：彩色装配、工程轴测、二维正交、同毫米比例三视图；世界 XYZ 方向轴可选四位置，
  沿外包络中心的有序轴展开、单件可控拉远、稳定自动配色与自定义颜色。
- **读数与参考**：默认关闭的全局外包络尺寸边缘读数；随模型毫米尺度收敛的受限地面网格。
- **失败保护**：CAD 转换可超时/取消，失败或取消时原设备与资料保持不变，并如实区分“已保存但打不开”。
- **单机运行**：交付目录自带 Qt 与 CAD 运行库，双击即用；不写注册表，不访问网络，数据不出本机。

## 快速开始

使用者（拿到交付目录后）：

```text
双击 设备查看器.exe          → 打开设备查看器并载入内置样例设备
双击 启动设备查看器.cmd      → 等效入口，出错时停窗显示原因
```

开发者（源码构建，已验证环境为 Windows + Qt 6.11.1 MinGW64 + GCC 13.1.0 + CMake 3.30.5 + Ninja 1.12.1）：

```powershell
# 配置 + 构建 + 部署 Qt 运行库 + 同步 CAD 运行库 + 全量 CTest
.\refactor\build.ps1

# 运行源码版设备查看器（产物在 build-refactor\bin\qt_sqlite_demo.exe）
build-refactor\bin\qt_sqlite_demo.exe --equipment-view

# 打包成交付目录（只复制运行所需文件，不复制源码、测试、资料库与凭证）
.\refactor\package.ps1 -OutputRoot <交付目录路径> -BuildDirectory build-refactor -Force
```

命令行参数：`--equipment-view`（默认）、`--record-view`（保留的旧“记录示例”窗口）、
`--database <文件>`、`--equipment-check`（只输出数据后退出）、`--smoke-test <png>`。

## 架构与实现要点

分层与单一职责（详细导读见 [`docs/architecture.md`](docs/architecture.md) 与
[`refactor/docs/package/02-技术说明.md`](refactor/docs/package/02-技术说明.md)）：

| 模块 | 职责 | 关键约束 |
| --- | --- | --- |
| `equipmentwindow.*` | 界面、清单、属性面板、导入入口 | 不执行 SQL，不持有业务状态的第二份副本 |
| `equipmentcontroller.*` | 当前设备、零件、选中、隐藏与隔离状态的唯一来源 | 界面与场景都从它取状态 |
| `equipmentrepository.*` | SQLite 结构校验、参数绑定事务、读取与回滚 | 不操作界面；结构校验失败拒绝启动而不是清库 |
| `equipmentimporter.*` / `cadresultparser.*` | JSON 与 CAD 转换结果的严格校验 | 校验失败不改变调用方输出；整份拒绝而不是交付半个模型 |
| `cadimportprocess.*` | 启动私有转换进程并约束其生命周期 | 超时、取消、退出确认；不联网、不上传模型 |
| `meshgeometry.*` | 网格拓扑校验与 EVM1 二进制编解码 | 顶点/三角计数与字节长度必须自洽 |
| `sceneview.*` | 几何生成、相机、拾取、OpenGL 绘制与软件回退 | 不访问数据库；显示偏移只是内存副本 |
| `recordstore.*` / `mainwindow.*` | 保留的旧“记录示例”功能 | 与设备查看互不影响 |

几个具体实现点：

- **曲面平滑着色**：三角面每个角点带顶点法线——长方体按面法线保持硬边，圆柱侧面用解析径向法线，
  STEP 网格按共享顶点累加相邻面法线（夹角超过 50° 仍按硬边处理）；光照为半球环境光 + 单向漫反射。
  这解决的是“看起来有锯齿”的真实原因：逐面片平光，而不是采样不足。
- **真实抗锯齿**：三维绘制进自建帧缓冲，请求 4 倍多重采样，并按“每个逻辑像素至少 2×2 渲染像素”
  超采样解析回控件；实际采样数取自本次绘制的 FBO 并写入渲染描述，不按请求值宣称。
- **方向轴**：方向取世界轴在相机空间的真实投影（不做归一化，接近视线方向时自然压短）；
  右下角按网页版同一管线绘制（120 像素画布光栅化后平滑缩放到 105 像素显示）。
- **软件回退**：没有原生图形上下文时回退到画家排序的软件投影，并用 `rendererDescription()`
  如实报告当前路径，测试据此断言。
- **只读参数**：展开与拉远只是显示偏移（毫米副本），原始位置、尺寸与网格不回写资料库。

## 已知限制与未实现

- 尺寸读数是**全局外包络**，不是制造级标注：不支持公差、基准与工程图导出。CAD 编辑、布尔运算、
  IGES 与厂商原生格式（`.sldprt`、`.catpart`）未实现。
- 只接受闭合实体；开放面、壳、线或混合文件整份拒绝。
- 只在当前这台 Windows 电脑、当前 Qt 版本上验证；未在其它机器、高 DPI 多显示器组合、
  十万级三角以上装配与长时间连续运行下做量化验证。
- 参数只能查看，不能编辑回写；展开与拉远不代表真实装配顺序、运动或碰撞约束。
- 团队共享库/工艺批注：已按用户要求移除（历史实现见标签 `v1.1.1`），当前版本无多人协作能力。
- 以上结论只覆盖本机自动检查与原生图形验收；其它机器、其它 Qt 版本、长期运行与大型装配的表现未验证。

## 数据与恢复

运行资料库只存在本机（`data/records.sqlite`，用 `--database` 可改路径），不随仓库与交付包分发。
源码用 Git 提交与版本标签管理，数据库备份与源码检查点分开进行；回退源码不能恢复数据库，
因此不要用 `reset --hard` 或 `clean` 处理数据问题。
